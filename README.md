# magasploit

magasploit is a lightweight reconnaissance and exploitation framework designed specifically for Termux.

## Features
* **spider**: Web directory discovery.
* **portscan**: Fast TCP port scanner.
* **dnslookup**: Fetch DNS records via Google API.
* **whois**: Domain ownership information.
* **iptracker**: Real-time IP geolocation.

## Quick Installation
Copy and paste this command into your Termux terminal:

```bash
curl -sL https://raw.githubusercontent.com/uyziu7/mgf/main/install.sh | bash
```
